# TRVZB Control Card 0.3.0

First public release candidate for SONOFF TRVZB valves using Zigbee2MQTT.

- Compact temperature controls, Auto/Manual/Off modes, heating status, and battery level.
- Weekly schedule editor with custom temperature presets, time slots, and copying between days.
- Temporary temperature adjustments in Auto until the next scheduled change.
- Child lock, open-window detection, temperature source, and frost protection settings.
- Home Assistant entity details and history from the card title.
- English and Russian translations, light and dark themes, and 12/24-hour time formats.

Install through a HACS custom repository or download `trvzb-control-card.js` for manual installation. See the [README](../../README.md) for setup and usage.

## Compatibility

Tested with Home Assistant 2026.4.1, Zigbee2MQTT 2.13.0, and TRVZB firmware 1.4.4.

Saving schedules and presets requires an administrator account and a dashboard edited through Home Assistant. Dashboards loaded from YAML files are not supported by the schedule editor. Auto adjustments require a scheduled temperature change within 24 hours and have one-minute precision.
